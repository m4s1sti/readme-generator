## Features

- Live visual preview and raw Markdown output
- Customizable banner colors and optional text
- Selectable tech stack badges
- GitHub stats and trophy card integration
- Social media and contact links
- One-click copy and download

## Built With

- HTML5 and Tailwind CSS
- Vanilla JavaScript
- Shields.io and Capsule Render APIs

## Usage

1. Open the tool in your browser.
2. Enter your profile details, GitHub username, and social links.
3. Select your tech stack badges.
4. Copy or download the generated Markdown code.
